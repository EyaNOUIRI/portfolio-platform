# Portfolio Platform

Professional portfolio platform showcasing skills in:
- AI Engineering
- Software Engineering
- QA Engineering (ISTQB)
- Web Engineering

## Architecture
- Frontend: React (TypeScript)
- Backend: Spring Boot (Microservices)
- Database: PostgreSQL
- AI: LLM-based Chatbot with RAG
- QA: Unit, Integration & E2E tests
- DevOps: Docker & CI/CD
